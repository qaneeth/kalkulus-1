Coba dan jelaskan

  1. Pilih x², n = 4. Bandingkan kiri dan kanan. Gunakan sifat naik untuk menjelaskan posisinya terhadap nilai limit.
  2. Pilih 9 − x² dan n = 10, 20, 50. Cocokkan hasil dengan Contoh 6.3.3.
  3. Pilih x − 1 pada [0, 2]. Mengapa integralnya nol, tetapi luas geometrisnya tidak nol?
  4. Untuk fungsi x pada [1, 2], pilih titik tengah. Mengapa hasilnya tepat 1,5 bahkan dengan n = 1?
Lihat arah pembahasan

Fungsi naik memberi hampiran kiri di bawah dan kanan di atas; fungsi turun memberi arah sebaliknya. Jumlah berhingga bergantung pada titik sampel. Limit untuk fungsi kontinu tetap sama ketika semua bagian mengecil. Pada fungsi bertanda, kontribusi positif dan negatif dapat saling meniadakan. Titik tengah tepat untuk fungsi linear.

Antiturunan yang dipilih
Nilai F(x₀)
Kemiringan F′(x₀) = x₀²

Kurva abu-abu menunjukkan beberapa antiturunan pembanding. Kurva berwarna menunjukkan F(x) = x³/3 + C yang dipilih; garis putus-putus adalah garis singgung.

Coba dan jelaskan

  1. Pertahankan x₀. Geser C. Apa yang berubah? Apa yang tetap?
  2. Mengapa informasi F(0) = 2 memilih tepat satu kurva?
  3. Tuliskan pemeriksaan bahwa turunan x³/3 + C selalu x².
Lihat arah pembahasan

C menggeser grafik secara vertikal dan mengubah nilai F, tetapi tidak mengubah turunan pada absis yang sama. Kondisi F(0) = 2 menetapkan C = 2.
